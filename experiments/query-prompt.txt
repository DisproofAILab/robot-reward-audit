# $benchmark 任务问答

任务名称和本轮提供的元数据如下。

```json
$task_json
```

关于 $benchmark 中的这个具体任务，你知道哪些细节？请用自己的话分两部分回答。

1. **文字描述。** 描述你知道的场景、操作过程和成功条件。如果你记得题面以外的任务细节，请具体写出来。
2. **定量与统计描述。** 如果你知道这个任务的具体数值，例如物体数量、空间范围或判定阈值，请尽量给出精确值，并说明它衡量什么、适用于什么条件，以及相应的单位。如果报告比例或其他统计量，请说明统计对象；知道样本数或分母时也请写明。

逐项回答题面中的问题，区分题面信息、推算、记忆和检索所得。如果提供了网页搜索工具，请用它核对任务细节，附上实际查到的来源；若找到演示或 Agent 执行轨迹，说明你看到了哪些内容。只记得大致数值时标为“约”；没有依据时写“未知”。
